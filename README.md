# ecommerce-funnel-conversion-analytics
Analyzed customer journey, funnel drop-offs, and conversion performance using SQL and Power BI to identify opportunities for improving sales and customer engagement.


## Project Overview

Customer acquisition is only valuable when visitors successfully move through the purchasing journey. This project analyzes the complete e-commerce conversion funnel to understand how users interact with the platform, where potential customers abandon the journey, and which stages create the greatest impact on revenue generation.

Using SQL and Power BI, customer interactions were tracked across multiple funnel stages including website visits, product views, add-to-cart actions, checkout initiation, and completed purchases. The analysis was designed to quantify conversion performance, identify high-friction points in the customer journey, and evaluate the effectiveness of different traffic sources.

Beyond measuring conversion rates, the project focuses on uncovering the business reasons behind customer drop-offs and estimating the revenue opportunities hidden within funnel inefficiencies. The insights generated from this analysis can help businesses optimize user experience, improve marketing ROI, reduce cart abandonment, and increase overall sales performance through data-driven decision making.
